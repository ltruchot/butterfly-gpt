# Dynamic image — blur + floating

The signature look of the theme: pass both <code>image</code> and
<code>upperImage</code>. The background blurs at <code>filter: blur(3px)</code>
and the foreground image floats with a soft shadow.

```yaml
layout: dynamic-image
image: /butterflies-hero.png
upperImage: /butterflies-blur.png
equal: true
left: false
```
