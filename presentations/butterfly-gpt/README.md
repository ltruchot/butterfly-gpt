# Butterfly GPT

Slides for **Butterfly GPT**, built on [Slidev](https://sli.dev) with the
[`slidev-theme-light-icons`](https://github.com/lightvue/slidev-theme-light-icons) theme.

```sh
# from the monorepo root
vp install
vp run @vp-monorepo-butterfly-gpt/butterfly-gpt#dev
```

Open <http://localhost:11117>.
